# Object-Oriented Programming – Laboratory Assignments

This repository contains three laboratory assignments from an Object-Oriented Programming course in C#.

The labs focus on important OOP concepts such as encapsulation, inheritance, interfaces, abstract classes, generics, and reusable software design.

---

## Lab 1 – N-Puzzle

This lab focuses on designing and implementing a playable N-Puzzle game using object-oriented principles.

The player selects the board size and moves the empty space using the keyboard until the puzzle is solved.

### Main Features

- Selectable board size
- Randomized solvable puzzle
- Keyboard controls
- Move counter
- Colored numbered tiles
- Console-based user interface

### Learning

- Encapsulation
- Data hiding
- Cohesion
- Coupling
- Information Expert principle
- Class design
- Separation of game logic, input and rendering
- Object-oriented problem solving

---

## Lab 2 – Bounce

This lab focuses on inheritance, interfaces and abstract classes.

The application contains moving balls and different obstacles that interact with them.

The obstacles include:

- Vertical lines that change the X-direction of the ball
- Horizontal lines that change the Y-direction of the ball
- SpeedUp boxes that increase ball speed
- SpeedDown boxes that decrease ball speed

### Learning

- Inheritance
- Interfaces
- Abstract classes
- Polymorphism
- Code reuse
- Shared behavior between related classes
- Designing class hierarchies
- Graphical programming with C#

---

## Lab 3 – HashDictionary

This lab focuses on implementing a generic dictionary class in C#.

The goal is to create a custom:

```text
HashDictionary<K, V>
that implements the IDictionary<K,V> interface without using the built-in C# Dictionary.
The assignment also includes a GeoLocation class that can be used as a key in the dictionary.
Main Concepts
- Generic types
- Hashing
- Key-value storage
- Equality
- Hash codes
- Dictionary interfaces
- Collection interfaces
- Enumeration
The implementation works with interfaces such as:
- IDictionary<K,V>
- ICollection
- IEnumerable
- IEnumerator
Learning
- Generics
- Interfaces
- Interface inheritance
- Hash tables
- Key-value collections
- GetHashCode()
- Equals()
- Iteration and enumeration
- Custom collection design
- Testing generic data structures
Technologies
- C#
- .NET
- Object-Oriented Programming
- Console applications
- Windows Forms
